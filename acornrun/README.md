# Acorn Run

Acorn Run is an original side-scrolling Fyne platform game for desktop, mobile,
and browser builds. Guide a woodland courier over grassy platforms, collect
acorns, bounce on beetles, break brittle logs, and reach the treehouse.

Controls: left/right arrows or A/D to move, Space/X/up arrow to jump, Z to run,
P to pause, R to restart, M to mute, and Escape twice to return Home. Touch
screens support tap-to-jump and swipe-to-move.

The platforming and collision logic adapts code from the MIT-licensed
JavaScript game in [reruns/mario](https://github.com/reruns/mario). Acorn Run
uses original characters, level design, artwork, and synthesized sound. It
does not include Nintendo graphics, audio, or level layouts. The upstream MIT
license is included in this folder.
