# Moria

Moria is a side-scrolling platform game for desktop, mobile, and browser builds.
Move through an original crystal cavern, collect crystals, jump on cave
crawlers, break cracked stone, and reach the ancient gate.

Controls: left/right arrows or A/D to move, Space/X/up arrow to jump, Z to run,
P to pause, R to restart, M to mute, and Escape twice to return Home. Touch
screens support tap-to-jump and swipe-to-move.

The movement and collision logic is a Go adaptation of the MIT-licensed
JavaScript game in [reruns/mario](https://github.com/reruns/mario). This port
uses original level design and artwork and does not include Nintendo graphics,
sounds, or level layouts. The upstream MIT license is included in this folder.
